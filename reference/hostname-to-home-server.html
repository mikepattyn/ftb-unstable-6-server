DNS record (this is the “URL” for Minecraft)

ftb-unstable.mikepattyn.nl.    300    IN    A    YOUR.PUBLIC.IPV4

A record RDATA is only an IPv4 address — RFC 1035 §3.4.1. Wiki: point it at the external IP — Minecraft Wiki.

The rest of the path (not DNS)

  1. Router: WAN TCP (and UDP if needed) → Mac LAN IP, same port the app listens on.
  2. Mac: DHCP reservation so the LAN IP does not drift.
  3. Process: Docker publishes 25565:25565/tcp on this host.
  4. Firewall: allow inbound on that port.

Check

dig +short A ftb-unstable.mikepattyn.nl
# must print YOUR.PUBLIC.IPV4
# must not print 192.168.x.x / 10.x.x.x / 172.16–31.x.x / 100.64–127.x.x

Private and shared ranges

RFC 1918 private: 10/8, 172.16/12, 192.168/16. RFC 6598 CGNAT: 100.64/10. None of these belong in a public A record.
